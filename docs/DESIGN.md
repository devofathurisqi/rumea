# Design reference and implementation

The supplied brand image is a logotype composition, not a website screenshot. Its evidenced features are warm ivory, restrained antique gold, thin high-contrast serif letters, wide letter spacing, a short horizontal rule, centered alignment, and abundant whitespace. “Opsi 1” and explanatory annotations were excluded.

The image does not contain navigation, cards, buttons, a page grid, or product photography. Those elements were designed as consistent extensions of the brand, rather than described as features present in the reference.

| Element | RUMEA treatment |
|---|---|
| Background | Paper `#fcfaf6`, ivory `#f7f4ed`, sand `#eee8dc` |
| Accent | Antique gold; text/button gold `#886a3b`, darker accent `#816337` |
| Typography | Locally hosted Cormorant Garamond and DM Sans; thin serif headings and restrained sans-serif controls |
| Logotype | Widely spaced uppercase serif, independent of annotation text |
| Navigation | Centered wordmark with compact shop links and quiet line icons |
| Headings | Fluid editorial scale; serif italics emphasize selected words |
| Cards | Photography first; material, name, retail/inquiry state, and functional color controls |
| Grid | Four columns desktop, two mobile; asymmetrical editorial compositions between sections |
| Spacing | Broad section spacing, fine dividers, restrained text measures |
| Images | Authentic collection photos; portrait 3:4 and 4:5 crops; contain treatment for product sheets |
| Borders | One-pixel warm neutral lines |
| Radius | Square panels/buttons; circular color swatches and small icon controls |
| Buttons | Solid gold primary action, quiet outlined secondary action |
| Decoration | Small numbering, hairline rules, editorial captions |
| Responsive | Mobile hero stacks copy and photography; two-column discovery and products; full-height native menu/filter/bag dialogs |
| Motion | CSS entrances, restrained hover, image crossfades, IntersectionObserver reveals; no animation library or scroll interception |
| Accessibility | Native dialog focus management, inert backgrounds, Escape dismissal, semantic controls, focus rings, 24px swatch hit areas, and reduced-motion support |

The ivory/gold direction is derived from the supplied image. The burgundy background comes from authentic product photography. No stock fashion photography, generated model photos, fabricated testimonials, promotions, or stock indicators were introduced.

Body text, prices, and buttons use darker gold/muted colors for legibility. The reference's extremely pale decorative lettering was not copied into small shopping controls.
